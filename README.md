# FreelanceKampus (GUI JavaFX)
Nama: Zahra Chintya Bela | NPM: 2517052012

Jalankan: klik kanan `Launcher.java` > Run File, atau `mvn clean javafx:run`.

Alur: halaman depan -> pilih Penyedia / Pemesan -> halaman masing-masing (ada tombol Kembali).

- Tahap 1: layout VBox/HBox/GridPane, Label, TextField, Button, ListView
- Tahap 2: setOnAction (pindah halaman, simpan profil, tambah jasa, pesan jasa, proses & selesaikan pesanan)
- Tahap 3: Alert untuk kolom kosong/belum dipilih + try-catch NumberFormatException untuk harga
- OOP: Pengguna -> Penyedia, Pemesan; class Jasa, Pesanan; encapsulation (private + getter/setter)
